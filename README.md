## 📖 About the Project

This repository contains the source code for the **414 Urban Dance Academy (414 UDA)** website. The platform serves as the digital front door for the academy, showcasing their vibrant community, dance classes, event galleries, and schedule across two locations in Neuss. 

The site is designed with a warm, modern aesthetic (Studio Daylight Theme) and is fully optimized for mobile devices, offering a seamless experience from browsing classes to booking a trial session (Probetraining).

## ✨ Features

- **Modern UI/UX:** A bespoke "Daylight Theme" featuring warm bone backgrounds (`#F6F1E7`), deep coral-orange accents (`#C94020`), and smooth scrolling.
- **Responsive Design:** Flawless experience across desktop, tablet, and mobile devices.
- **Interactive Schedule:** Swipeable, location-based timetables for easy mobile viewing.
- **Video Testimonials:** Integrated, responsive HTML5 video players showcasing community feedback.
- **Dynamic Gallery:** A custom-built, lightweight image lightbox for viewing event photos.
- **Probetraining Contact Form:** Integrated with Web3Forms for secure, serverless email submissions.
- **GDPR Compliant:** Custom cookie consent banner controlling the loading of Google Maps embeds.

## 🛠️ Tech Stack

This project is built with a focus on performance, avoiding heavy frameworks in favor of native web technologies:

- **HTML5:** Semantic and accessible markup.
- **CSS3:** Advanced layouts using Flexbox & Grid, CSS Variables for theming, and smooth CSS animations.
- **Vanilla JavaScript (ES6):** Custom logic for mobile navigation, scroll-reveal animations (Intersection Observer), lightboxes, and form handling.
- **Node.js & Sharp:** Automated image compression and WebP conversion for peak performance.
